# Turkey-Production-Analysis
Built and back-tested a linear regression forecast on 40 years of USDA turkey production data; identified systematic overestimation against 2024 actuals and corrected it with a 20M-lb/year downward adjustment. Applied BLS Poultry CPI (vs. general CPI, r=0.61) for inflation-adjusted valuation, producing a validated 2025 production forecast.
